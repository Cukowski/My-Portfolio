# Selçuk Ata Aksoy — Portfolio

Personal portfolio presenting engineering software experience, selected C/C++ and Python projects, technical tutorials, and company-based bachelor’s thesis interests.

## Contents

- `index.html`: profile, practical experience, selected projects and direct contact links.
- `style.css`: responsive layout using the existing purple visual theme.
- `script.js`: navigation highlighting.
- `images/`: existing portrait and background assets.

## Preview and hosting

Open `index.html` in a browser or serve the repository with a static HTTP server. No build step is needed. The repository uses GitHub Pages; verify the configured publishing source before deployment.

Contact links use email and LinkedIn directly. No contact form or backend is required.

The original layout was inspired by the Code and Create course *10 Mega Responsive Websites with HTML, CSS, and JavaScript*.
